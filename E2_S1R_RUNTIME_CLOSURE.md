# S1-R runtime closure and scope

The new implementation is `src/e2_s1r/runtime.py` with `broker.py`. The S1 prototype and its negative certification remain preserved. Frozen R3, the copied frozen R2 callable and recognizer are unchanged. No provider client is invoked; mock ModelInvocation envelopes retain the MiniMax-only profile.

## Authority and state

The trusted launcher issues opaque principal-bound Session capabilities for the same coordinator and two generic workers. Model JSON cannot select its calling principal, provenance category, authorization grant, tool identity, private initialization, evaluator access, shell/web or external connectors. One generic action grammar and fully connected internal graph applies to every task; there is no task-ID branch or task DAG. Calls execute serially; recipient queues are FIFO. Shared action caps, typed failures, explicit retry and termination behavior are arm-independent. The certification cap is1000actions per fixture runtime; it is not a scientific token-budget claim.

Immutable Envelope records carry producer, owner, audience, family, category, surface, tool identity, authorization projection and parent artifacts. Runtime-derived publications conservatively inherit the actor's actually visible context references; this is an over-approximation of semantic dependence, not a claim of exact causal attribution. Changed release views receive new sequential artifact IDs with the original view as parent. A payload reference is never reused for changed bytes. Data-bearing state keys stay in the mediated payload; state/proposal/effect IDs are generated by trusted code.

The sole arm selector invokes the unchanged EXACT_IFC `ifc_safeview` or frozen FLOWFENCE_R2 callable. No task IDs, expected labels, gold fields or attack annotations are passed as oracle decision inputs. Public task IDs can occur as ordinary data in a task artifact. Whole-artifact quarantine that cannot satisfy the same structured source schema yields a typed invalid-release rejection, with no repair or fabricated success.

Task state, principal private/scratch state, shared artifact state, queues/history, tool results and final state have service-owned storage. All public Session reads return detached JSON values. Shared updates prepare a complete immutable replacement, validate the owner and ordinary integer revision, mediate the full payload, and commit once. Deletion is represented by the resulting root replacement; PreparedEffect references the originating StateProposal. Stale, unauthorized and replayed commits are rejected. A rejected release does not create a visible queue item, state update, history entry or final answer. Authorized TRUSTED_PRIVATE self-context is checked by owner and is not filtered as untrusted text; exported values cross ordinary publication boundaries.

## Actual BIRD capability

The broker uses the exact restored S1 PostgreSQL14.24 snapshot, UTF8/C locale, serial query engine and30s statement timeout. The original EX scorer separately retains its unchanged30s source timeout implementation. Source DB IDs select trusted profiles, never connection parameters supplied by a model. The original dump's75tables remain in one PostgreSQL database; per-profile roles have SELECT on exactly their source tables and no table writes. Temporary-object and public-schema creation rights are absent. Table contents and gold SQL are unchanged.

A PostgreSQL AST parser (`pglast8.4`) permits one SELECT/WITH statement over source tables/CTEs, rejects mutating CTEs, INTO/locking, multiple statements, system/other-schema relations and administrative/IO functions. The explicit family-wide data-function profile includes ordinary arithmetic, text/date, aggregation/window and JSON operations required by the accepted pool. It is not a general PostgreSQL administration client. All500 original reference-query fixtures pass the same broker profile; no task-specific exception was added. No query sorting, tolerance comparator or result repair is used. This certifies the accepted benchmark task capability, not every extension/function available on an arbitrary PostgreSQL server.

SQL arguments are released to the actual registered `readonly_sql` tool identity (unchanged frozen fallback privilege), not to the calling worker. Tool identity and connection authority come from the broker. Results/errors are private drafts until B5, then B3/B6 publication and B1 consumption. Errors retain structured source SQLSTATE and retry class without exposing raw exception strings. Non-JSON native values use explicit type/text representation, including Decimal/date/time/binary and non-finite float fixtures. Original EX evaluates released SQL directly, independent of this observation serialization.

Schema comes from original table identities/descriptions and actual restored PostgreSQL columns/constraints, never gold SQL. UTF-8/BOM and Windows-1252 descriptions are decoded with exact byte roundtrip, without replacement characters. `schema_coverage.json` enumerates every table, column and source constraint. All500 task mappings retain question/db_id/evidence/full allowed schema/descriptions, plus the same read-only capability. No evaluator-private field enters the TASK allowlist.

## Seven-boundary domination argument

`mediation_paths.json` enumerates every exposed actor information path per family, with producer, consumer, API, provenance issuer, boundary, test and bypass result. The closed Session API is the modeled capability boundary. No actor-supplied callback, connection, backing dictionary, arbitrary Python or evaluator input is accepted.

Initialization creates immutable typed objects. Actor outputs are proposals. Context and shared reads use B1/B3; messages/history use B2/B3/B6 and B1 on consumption; state updates cannot commit before B6; SQL cannot execute before B4; broker drafts cannot be observed before B5; final/export cannot publish before B7. Each new visible value therefore derives from an accepted release or authorized private self-read. State ownership and detached values prevent another API from mutating a committed object. Unknown actions have no connector or effect path.

Original scorers are separate trusted consumers of actual released native output. P0 EvaluatorJob records keep private reference identifiers outside Runtime, and no evaluator callback/value is returned to a Session. Gold is used only as an explicit deterministic **output fixture** for reproduction, never an oracle task/context input. Safe evidence contains counts/booleans/source IDs, not full trajectories or private fixture values.

**Modeled bypasses remaining:0**, within these declared trusted-service/capability assumptions and tested accepted profiles. This is not OS-wide information-flow security, a Python reflection sandbox, a covert-channel guarantee or certification of a future provider integration. The detector retains its original limitations; mediation coverage is distinct from universal detection of transformed secrets.
