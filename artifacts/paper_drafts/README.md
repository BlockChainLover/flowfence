# Paper Draft Artifacts

This directory contains draft paper prose generated from committed evidence tables and high-level summary artifacts.

These drafts are not integrated into `main.tex`. Human review is required before any text is copied into a paper.

The draft text must not be treated as final paper text. It is a scoped starting point for a Results section and claim-traceability review.

Raw traces, raw provider outputs, prompts, event JSONL, policy JSONL, individual per-run metrics, credentials, and secrets were not used.

MiniMax is the only real provider represented. The MiniMax evidence is synthetic-runtime coverage, not production or real browser/desktop/computer-use deployment evidence.
