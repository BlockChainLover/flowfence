\section{Related Work}

\paragraph{Prompt injection and tool-integrated agents.}
Indirect prompt injection shows that adversarial instructions embedded in retrieved or tool-returned data can steer LLM-integrated applications and API use~\cite{greshake2023indirect}. General prompt-injection benchmarks formalize attack and defense evaluation for LLM-integrated applications~\cite{liu2023promptinjection}. AgentDojo evaluates prompt injection attacks and defenses for tool-using agents, while Agent Security Bench systematizes agent attacks and defenses across tool and memory settings~\cite{debenedetti2024agentdojo,zhang2024asb}. FlowFence-Lite follows this benchmark-oriented tradition but focuses on propagation across internal channels.

\paragraph{Memory poisoning and extraction.}
AgentPoison shows that agent memory and knowledge bases can be poisoned~\cite{chen2024agentpoison}. MEXTRA studies black-box memory extraction and motivates safeguards for agent memory~\cite{wang2025mextra}. Our P0 setting is adapted from the memory-poisoning direction, but we do not claim official AgentPoison reproduction.

\paragraph{Multi-agent propagation and topology-aware guardrails.}
Agent Smith motivates infectious cascade risk in multi-agent systems~\cite{gu2024agentsmith}. G-Safeguard studies topology-aware treatment for LLM-based multi-agent systems~\cite{wang2025gsafeguard}. FlowFence-Lite differs by emphasizing policy-aware shared-memory and shared-workspace containment.

\paragraph{Agent privacy and memory systems.}
AgentDAM studies privacy leakage evaluation for autonomous web agents~\cite{zharmagambetov2025agentdam}. A-MEM studies agentic memory for utility~\cite{xu2025amem}. These works motivate privacy metrics and memory-aware evaluation, while FlowFence-Lite focuses on runtime containment over shared artifacts and cross-principal flows.

\paragraph{Information-flow and least privilege.}
FlowFence-Lite is also related to classic information-flow control and least-privilege systems. We use these ideas pragmatically as runtime policy checks, leases, safe views, and quarantine rather than as a full formal proof system.
