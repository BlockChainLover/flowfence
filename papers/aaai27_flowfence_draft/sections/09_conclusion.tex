\section{Conclusion}

Privacy leakage in multi-agent LLM systems is a propagation problem over messages, memory, workspaces, tools, and final outputs. FlowFence-Lite provides a practical runtime containment layer based on policy-aware safe views, quarantine, privilege signals, and topology/fanout features. Across an adapted retrieval-memory evaluation, deterministic MAS benchmarks, a MiniMax-backed multi-agent synthetic-runtime coverage experiment, and non-oracle held-out validation, the committed evidence supports configured containment claims while preserving explicit limitations. Future work should expand providers, evaluate browser/desktop environments, add learned risk scoring, and deepen module-level ablations before making broader deployment claims.
