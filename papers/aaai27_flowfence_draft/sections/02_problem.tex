
\section{Problem Definition and Threat Model}

\paragraph{Runtime model.}
We model a multi-agent runtime as a tuple $(A,P,O,E,G)$. $A$ is a set of agents and $P$ is a set of principals. Each agent acts for a principal and may read or write runtime objects $O$: private memory cells, shared memory entries, workspace documents, messages, tool calls, and final outputs. $E=(e_1,\ldots,e_T)$ is a time-ordered event sequence. Each event records an actor, optional recipient, channel, target object, target zone, payload hash, redacted preview, causal parents, and defense decision. The causal edges induce an event graph $G$.

\paragraph{Secrets and policies.}
A protected item $s$ has an owner, a raw value, authorized recipients, an allowed abstraction level, and forbidden channels. A policy may allow abstract disclosure while forbidding raw disclosure. For example, a vendor-facing update may mention that a budget constraint exists while forbidding the exact budget, internal incident rationale, customer identifier, or credential-like marker. Let $\mathsf{raw}(s,x)$ indicate that payload $x$ contains the raw value of $s$, and let $\mathsf{auth}(s,e)$ indicate that event $e$ is authorized to carry that raw value.

\paragraph{Leakage.}
An event has \emph{unauthorized raw leakage} if $\exists s$ such that $\mathsf{raw}(s,e)$ and $\neg \mathsf{auth}(s,e)$. It has \emph{external leakage} if the same exposure reaches an external recipient, final output, or exfiltration-capable tool. We separately track internal leakage because a final output may be safe even after sensitive data has propagated through shared state.

\paragraph{Propagation metrics.}
A contaminated event is one whose payload or metadata is derived from an injected or poisoned source. Cascade size is the number of distinct contaminated events or artifacts reachable through $G$. Cascade depth is the longest contaminated causal path. Privilege reach is the maximum privilege level touched by contaminated content. A topology effect is observed when these metrics differ materially across chain, star, and blackboard topologies in the configured benchmark.

\paragraph{Threat model.}
The adversary can place malicious instructions in data that agents may treat as context: retrieved memory, summaries, shared workspace artifacts, or inter-agent messages. We evaluate retrieval poisoning, summary poisoning, workspace poisoning, and communication hijacking. Direct attacks use obvious instruction phrases; indirect attacks launder sensitive-detail requests through intermediate artifacts; paraphrased attacks avoid the original trigger phrases while preserving the dangerous semantics.

\paragraph{Non-goals.}
We do not model OS compromise, network compromise, browser or desktop compromise, model-weight theft, production deployment, arbitrary adaptive attacks, human factors, or non-MiniMax provider generalization. The MiniMax evidence uses a synthetic deterministic multi-agent runtime with MiniMax final-writer calls. It is not a full autonomous browser/desktop/computer-use stack.
