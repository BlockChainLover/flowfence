
\section{Benchmark and Experimental Setup}

We use four evidence layers. Each layer is scoped and should not be interpreted as production deployment evidence.

\paragraph{P0 adapted retrieval-memory comparator.}
We first evaluate on an adapted AgentPoison full-ReAct retrieval-memory setting. The goal is to test whether runtime containment can block exposure and attack manifestation after poisoned content has been retrieved. This is not an official AgentPoison reproduction; it is a saved comparator axis for retrieval-memory containment.

\paragraph{Synthetic multi-agent runtime.}
The P1 benchmark contains four agents: planner, finance, document writer, and external vendor. The runtime supports private memory, shared raw memory, safe-view memory, shared workspace, quarantine, messages, tool-like sends, and final vendor-facing updates. The protected synthetic secrets include a budget value, internal incident rationale, customer reference, and credential-like marker. Safe traces redact these raw values.

\paragraph{Topologies.}
We evaluate chain, star, and blackboard topologies. Chain propagates through a linear sequence. Star uses the planner as a hub. Blackboard allows shared workspace artifacts to be read by multiple agents, creating higher fanout and a stronger propagation pathway.

\paragraph{Attacks and defenses.}
Attacks include no attack, direct and indirect summary poisoning, direct and indirect workspace poisoning, and direct and indirect communication hijacking. Held-out paraphrase variants avoid the earlier direct trigger phrases. Defenses are no defense, static ACL, prompt filter, FlowFence-Lite, FlowFence-Lite non-oracle, and the no-semantic-pattern ablation where applicable.

\paragraph{MiniMax-backed coverage.}
The canonical MiniMax experiment is a 252-run coverage matrix: 3 topologies, 7 attacks, 4 defenses, and 3 seeds. MiniMax is used only as the final writer in the synthetic deterministic MAS runtime. We also report a targeted MiniMax non-oracle validation with 72 runs over held-out paraphrase attacks.

\paragraph{Metrics.}
Task success measures whether the final vendor-facing update is usable and safe. Unauthorized raw leakage and external leakage measure policy violations. Cascade size and privilege reach measure propagation breadth and movement into higher-risk contexts. Oracle-annotation violations measure whether a defense variant used attack labels that would not be available in a real runtime.
