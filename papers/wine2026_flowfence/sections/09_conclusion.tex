\section{Conclusion}

Multi-agent LLM platforms make privacy a propagation problem. Sensitive information can move through memory, workspaces, summaries, messages, tools, and external outputs before a final answer is produced. FlowFence treats these runtime transitions as first-class governance surfaces: it mediates events, constructs policy-preserving safe views, quarantines raw content, narrows leases, and uses topology and privilege signals to limit downstream exposure. Across retrieval-memory and multi-agent workflow evaluations, the method closes intermediate raw and external leakage paths while preserving task completion. The broader implication is that AI-mediated online platforms should govern shared runtime state directly, rather than relying only on final-output filters.
