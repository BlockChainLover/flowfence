\section{Recognizer and Guard Implementation}
The complete 13-expression recognizer is printed in the main paper. Python \texttt{re.search} with \texttt{re.IGNORECASE} is applied to each original candidate string; the output is an OR. There is no additional normalization, semantic classifier, task label or evaluator input. The historical constant name containing ``HELDOUT'' does not imply vocabulary-held-out validation. Controlled A/B match existing lexical terms for private numeric limits/private finance values; public A/B match the operational-detail/internal-reference terms. These examples deliberately satisfy known coverage.

The implementation of R2 is in \texttt{src/e2\_s1/frozen\_r2.py}. It first calls the existing non-oracle guard, retains a prior hard block, then replaces the result with a constant quarantine marker when the original candidate matches and the target is a modeled propagation surface. The exact-value comparator follows \texttt{\_inspect\_\allowbreak ifc\_\allowbreak safeview}; it constructs a safe view only when the original candidate contains a registered raw value on a forbidden recipient or channel path. The common safe-view function also strips matching request phrases when invoked. Thus our explanation is not that the comparator is incapable of removing a matched phrase, but that a raw-free recognized instruction does not independently trigger that path.

The inherited guard includes risk and lease behavior absent from the simpler comparator. In public CLEAN FlowFence paths, 1,274 release decisions are recorded as lease downgrade, despite no quarantine or block. These are repeated event records, not 1,274 independent interventions or evidence of a utility effect. The runtime comparison is not a perfect one-switch ablation of all policy behavior. Complete mediation is assumed only for the explicitly modeled interfaces.

Among jointly completed pairs, success is R2/IFC 18/18 versus 18/18 in CLEAN, 15/17 versus 16/17 in A, and 17/17 versus 16/17 in B. The 13 IFC disclosure episodes generate 39 dependent propagation observations. They are not 39 independent failures.

For task cluster $j$, let $I_j$ contain its repetitions with both guards complete. The disclosure difference is
\[
 d_j=|I_j|^{-1}\sum_{r\in I_j}(D_{j,r,R2}-D_{j,r,IFC}),\qquad
 \bar d=6^{-1}\sum_{j=1}^{6}d_j.
\]
A has cluster differences $(-2/3,-1/3,-1/3,-1/2,0,-1/3)$, and B has $(-1/3,-2/3,-1/3,-1/2,-1/3,-1/3)$. Both have only two completed repetitions in the fourth cluster; the other clusters have three. Therefore the cluster-weighted estimates differ slightly from the episode-weighted fractions 6/17 and 7/17.

We enumerate all ordered samples of six cluster indices with replacement ($6^6$). The interval endpoints use empirical inverse-CDF order statistics at 2.5\% and 97.5\%, with index $\lceil pN\rceil-1$. Utility uses all three scheduled repetitions per cluster, assigning unsuccessful status to failed executions; matched-completed utility is additionally saved as a sensitivity calculation. The exact sign test discards zero differences and doubles the smaller binomial tail (capped at one). All of these calculations are post hoc. Six variants of a single scenario and adaptive prior development preclude interpreting the resamples as a representative task population. No multiplicity correction or claim of utility equivalence is made.

\section{Model Configuration and Known Missing Measurements}
Both studies use MiniMax-M2.7 at temperature 0. Each call has an output limit of 8192 tokens and a 240-second timeout. R3's actual client omits top-p, leaving an unrecorded provider default; E2-A explicitly sends top-p=0.9. Their context guards are respectively 20,000 characters and 160,000 request-message UTF-8 bytes. R3 permits two transport retries but uses zero; E2-A permits zero. Within each study the arms share the same configuration, but these two protocols must not be described as identical across studies.

The available evidence does not measure detector FPR/FNR on an independently labeled corpus, unseen/adaptive attack recall, a second topology or model family for these formal comparisons, recovery after terminal quarantine, or head-to-head performance against Fides, CaMeL or Task Shield. The fixed reconstruction failures are selected historical counterexamples, not a sampled attack-success rate. The saved E3 configuration uses IFC-SafeView and the pre-R2 non-oracle guard; it does not run R2. These versioned negative observations must not be reported as a new R2 experiment. These gaps remain open; the revision does not fill them with synthetic or inferred results.
